# 🚀 Final Commands to Run Your App

Your phone is detected! Now run these 2 commands:

---

## Command 1: Install the New Dependencies

In your Command Prompt, type:
```cmd
npm install
```

Wait for it to complete (30 seconds to 1 minute).

---

## Command 2: Run the App on Your Tecno Phone

After npm install finishes, type:
```cmd
npx react-native run-android
```

**This will:**
- ✅ Build the Android app (5-10 minutes first time)
- ✅ Install it on your Tecno phone (device: 147193756V006472)
- ✅ Launch the Health Tracker app automatically!

**You'll see progress like:**
```
info Running jetifier to migrate libraries to AndroidX
info Starting JS server...
info Building and installing the app on your device...
> Task :app:installDebug
Installing APK...
info Successfully installed the app
info Launching the app...
```

---

## 🎉 When It Works:

Your Tecno phone will show:
- Health Tracker app opens
- Green theme with bottom tabs
- Dashboard, Goals, Rewards, Meds, Settings

---

## ⚠️ If You Get Errors:

Copy the error message and send it to me. Common fixes:
- First build takes 5-10 minutes (be patient!)
- May need to accept licenses: Run `cd android && gradlew --version`
- Metro bundler should auto-start in another window
