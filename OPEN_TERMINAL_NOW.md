# ⚡ HOW TO OPEN THE TERMINAL RIGHT NOW

## QUICK METHOD - DO THIS:

Press these two keys together on your keyboard:

```
Ctrl + `
```

**(That's Ctrl + the backtick/grave accent key)**

The backtick key (`) is usually:
- Above the Tab key
- To the left of the number 1
- Below the Escape key

## OR USE THIS METHOD:

1. Look at the TOP of VS Code
2. Click **View** in the menu bar
3. Click **Terminal**

## OR THIS METHOD:

1. Look at the BOTTOM of VS Code window
2. You should see tabs: PROBLEMS | OUTPUT | DEBUG CONSOLE | **TERMINAL**
3. Click on **TERMINAL**

## WHAT YOU'LL SEE:

Once the terminal opens, you'll see text asking:
```
What is your first and last name?
  [Unknown]:
```

## WHAT TO DO:

1. Just press **ENTER** (accept the default)
2. It will ask more questions - press **ENTER** for each one
3. Finally it asks "Is this correct?" - type **yes** and press **ENTER**
